GOOD TO KNOW.

ก่อนเริ่มใช้งาน

คำตอบสั้น ๆ ที่อาจกำลังหาอยู่

Floaty ใช้บน macOS ได้ไหม?

ตัวโปรแกรมรองรับ Windows 64-bit ภาพ MacBook บนเว็บเป็นภาพจำลองสำหรับแสดงวิธีจัด Layout เท่านั้น

ต้องใช้บัญชีอะไรในการเข้าสู่ระบบ?

ใช้บัญชี Discord เพื่อเข้าสู่ระบบ และรอผู้ดูแลอนุมัติการใช้งาน เมนูและฟีเจอร์ที่เห็นจะขึ้นอยู่กับสิทธิ์ของบัญชีคุณ

อัปเดตเวอร์ชันใหม่ได้อย่างไร?

กดปุ่มตรวจอัปเดตในแอป เมื่อพบรุ่นใหม่สามารถอ่านรายละเอียด ดาวน์โหลด และเลือกติดตั้งเมื่อพร้อม แอปจะคืนค่าหน้าต่างเกมก่อนปิดเพื่อติดตั้ง

ถ้าต้องการคืนหน้าต่างเป็นเหมือนเดิมล่ะ?

ใช้ปุ่มคืนค่าทั้งหมดในแอป หรือปุ่มลัด Ctrl + Alt + R เพื่อคืนหน้าต่างที่จัดการอยู่กลับเป็นแบบเดิม
